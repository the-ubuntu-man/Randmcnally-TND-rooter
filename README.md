# Rand McNally TND Tablet Rooter

An automated Linux shell toolset for unlocking and rooting the **Rand McNally TND Tablet** commercial GPS tablet using MediaTek BROM mode and `mtkclient`.

> **Disclaimer:** Modifying system partitions and unlocking bootloaders carries inherent risks. Always back up your stock `boot`, `vbmeta`, and `recovery` images before flashing. Use this tool at your own risk. Additionally this tool will not turn on OEM Unlocking and this was only tested on the TND750. Sorry if OEM Unlocking is stuck off on your model but this script simply can't achieve that.

---

## Overview

The Rand McNally TND Tablet runs a locked-down build of Android 8.1 on a MediaTek chipset with public firmware images. This repository automates the Python environment setup and `mtkclient` execution required to dump partitions, disable verified boot (`vbmeta`), and achieve full root access.

## Repository Structure

* **`setup-venv.sh`** – Configures the required Python virtual environment and installs dependencies for `mtkclient`.
* **`mtkclient-executor.sh`** – Handles low-level MediaTek BROM communication, partition dumping, and flashing operations.
* **`main.sh`** – The primary entry point that guides you through the setup and rooting workflow.
* **`assets/`** – Supporting files and resources used during the rooting process.

## Usage

### 1. Clone the Repository
```bash
git clone https://github.com
cd Randmcnally-TND-rooter
```

### 2. Make Scripts Executable
```bash
chmod +x main.sh setup-venv.sh mtkclient-executor.sh
```

### 3. Run the Rooter
```bash
./main.sh
```

### 4. Enter MediaTek BROM Mode
1. Power off the **TND** completely.
2. [Insert your exact steps here — e.g., Hold the Power + Volume button while plugging in the USB cable].
3. Wait for `mtkclient` to detect the MediaTek preloader/BROM port and complete the automated process.

---

## Safety & Backup Recommendations

* **Keep Your Stock Backups:** Do not delete the original partition dumps generated by the script. Because factory firmware for the TND Tablet is not publicly hosted online, these backups are required to recover from a bootloop.
* **Magisk Setup:** Once rooted, install the Magisk Manager APK to manage root permissions and modules safely.
